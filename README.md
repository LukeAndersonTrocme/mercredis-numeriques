# Mercredis numériques

Des étudiant·e·s aux cycles supérieurs en biologie qui partagent leurs trucs pour le travail computationnel, un mercredi sur deux. Ce dépôt garde tout le matériel de la série.

## Sessions

| Date | Sujet | Aide-mémoire |
|---|---|---|
| 2026-10-14 | Organisation des scripts et des fichiers | [`2026-10-14-organisation/`](2026-10-14-organisation/) |
| 2026-11-11 | Git et GitHub | [`2026-11-11-git/`](2026-11-11-git/) |

## Avant de venir

1. Un compte sur [github.com](https://github.com).
2. *Optionnel* : Git installé (`git --version`).
3. Ton portable. Un navigateur suffit.

## Participer

Ajoute ta fiche dans [`participants/`](participants/) avec une pull request — c'est l'[exercice 1](2026-11-11-git/exercices/01-pull-request-web.md) de la session Git.

## Organisation du dépôt

```
mercredis-numeriques/
├── README.md                  # ce fichier : l'index de la série
├── participants/              # une fiche par personne
└── AAAA-MM-JJ-sujet/          # un dossier par session
    ├── README.md              # lien vers l'aide-mémoire, résumé
    └── exercices/             # s'il y en a
```

Les aide-mémoires eux-mêmes vivent sur [popgen.ca/lukezone](https://popgen.ca/lukezone) ; ce dépôt pointe vers eux plutôt que de les copier.
