# 2026-11-11 · Git et GitHub

Le modèle mental de Git, quatre questions auxquelles il répond (revenir en arrière, ne rien perdre, essayer sans casser, travailler à plusieurs), l'astuce « une phrase par ligne » pour les manuscrits, et tout ce que Git fait d'autre.

Aide-mémoire : [Git et GitHub, pour de vrai](https://popgen.ca/lukezone/introduction-a-git)

## Exercices

| | Où | Durée | Quoi |
|---|---|---|---|
| [**1**](exercices/01-pull-request-web.md) | en classe, navigateur | 10 min | Fork, ajoute ta fiche, ouvre une pull request |
| [**2**](exercices/02-pull-request-terminal.md) | à la maison, terminal | 15 min | La même chose, en ligne de commande |
| [**3**](exercices/03-ton-projet.md) | à la maison, ton projet | 15 min | `git init`, `.gitignore`, premier push vers un dépôt privé |
| [**4**](exercices/04-manuscrit.md) | à la maison, navigateur | 10 min | Corrige une phrase de [`manuscrit.md`](exercices/manuscrit.md), regarde le diff |

L'exercice 3 est celui qui compte. Les autres sont de l'entraînement.
