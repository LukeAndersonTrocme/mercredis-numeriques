# Exercice 4 · Une phrase par ligne

**À la maison · 10 min · navigateur**

Le but : voir pourquoi on écrit un manuscrit avec une phrase par ligne.

Le fichier [`manuscrit.md`](manuscrit.md) est un résumé (fictif) écrit avec une phrase par ligne. Chaque phrase contient une petite erreur : une faute, un mot en double, un accord raté.

- [ ] Dans ton fork, ouvre `2026-11-11-git/exercices/manuscrit.md` et clique sur le crayon (**Edit this file**).
- [ ] **Choisis UNE phrase** et corrige son erreur. Une seule.
- [ ] **Commit** sur une nouvelle branche, avec un message comme « Corrige l'accord dans la phrase sur l'échantillon ».
- [ ] **Ouvre la pull request** et regarde l'onglet **Files changed** : une seule ligne rouge, une seule ligne verte, la phrase entière. C'est tout l'intérêt.
- [ ] **Compare.** Dans la section *Le même paragraphe, sur une seule ligne* en bas du fichier, fais la même correction. Regarde le diff : laquelle des deux versions voudrais-tu relire dans un manuscrit de 40 pages ?

**Si GitHub annonce un conflit** (*This branch has conflicts*), c'est que quelqu'un d'autre a corrigé la même phrase avant toi. C'est normal, et c'est exactement ce qui arrive entre collaborateurs. Ferme ta PR et choisis une autre phrase.
