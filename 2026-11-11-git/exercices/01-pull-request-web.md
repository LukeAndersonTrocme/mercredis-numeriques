# Exercice 1 · Ta première pull request (navigateur)

**En classe · 10 min · aucun logiciel à installer**

Le but : faire le cycle complet *fork → modification → commit → pull request* une fois, en vrai, sans terminal.

- [ ] **Fork.** Sur la page du dépôt, clique sur **Fork** (en haut à droite), puis **Create fork**. Tu as maintenant ta propre copie, sous ton compte.
- [ ] **Crée ta fiche.** Dans *ton* fork, ouvre le dossier `participants/`, puis **Add file → Create new file**. Nomme-le `<prenom>.md` (minuscules, sans accents : `beatrice.md`, pas `Béatrice.md`).
- [ ] **Remplis-la.** Copie le contenu de [`participants/exemple.md`](../../participants/exemple.md) et complète-le.
- [ ] **Commit.** Clique sur **Commit changes…**. Écris un message qui dit ce que tu fais (« Ajoute la fiche de Béatrice »), puis confirme.
- [ ] **Pull request.** GitHub affiche un bandeau *This branch is 1 commit ahead*. Clique sur **Contribute → Open pull request**, relis le diff, puis **Create pull request**.
- [ ] **Regarde.** Ta PR apparaît dans l'onglet *Pull requests* du dépôt d'origine. On les fusionne ensemble à l'écran.

**Ce que tu viens de faire, en vocabulaire Git :** un fork (une copie du dépôt), un commit (une photo), et une proposition de fusionner ta photo dans l'historique commun.
